# 泡泡小勇士 · 3D 大冒险

一个给 **4-6 岁** 孩子玩的 3D 横版泡泡射击小游戏。浏览器直接打开就能玩，手机、平板、电脑都可以。

> 玩起来像"魂斗罗"，但不会流血、不会失败。

## 怎么玩

| 操作 | 屏幕按钮 | 键盘 |
|---|---|---|
| 前进 / 后退 | ◀ ▶ | `A` `D` / `←` `→` |
| 跳跃（可以二段跳） | ⤒ | `空格` / `W` / `↑` |
| 发射泡泡（按住连发） | 💧 | `J` |

- 泡泡会**自动瞄准**最近的小怪兽，孩子不需要对方向。
- 把小怪兽打成星星，跳起来吃空中飘着的金色星星。
- 跑 132 米会遇到戴皇冠的**大王**，打掉它彩虹门才会打开。
- 跑进彩虹门就赢了。

## 为什么适合 4-6 岁

- **没有死亡**：3 颗心，掉光后会出现"保护泡泡"并自动补满，不存在 Game Over。
- **不会卡关**：自动瞄准 + 泡泡可以往前也可以往回打，跑到哪都打得着。
- **不吓人**：没有枪、没有血，小怪兽都是圆滚滚的毛球，被打中会变成彩色纸屑。
- **大字大按钮**：按钮最小 84px，会用图形和语音提示，不认字也能玩。

## 本地运行

```bash
git clone <this-repo>
open index.html          # macOS，双击也行
```

单文件 710KB，three.js 已内联，**完全离线可用，零外部请求**。

## 修改与重新构建

```bash
curl -sL -o assets/three.min.js https://unpkg.com/three@0.158.0/build/three.min.js
python3 build.py         # 生成 dist/泡泡小勇士.html 与 index.html
```

源码结构：

```
src/game.js            游戏逻辑（世界生成 / 角色 / 敌人 / 泡泡 / 关卡流程）
src/style.css          HUD 与触屏按钮
src/index.tmpl.html    页面骨架
build.py               把 three.js、CSS、JS 内联成单文件
qa/                    Playwright 自动化验收脚本（不随仓库发布）
```

## 联调接口

游戏在 `window.GAME` 上暴露了调试接口，方便自动化测试：

```js
GAME.info()      // 当前状态快照
GAME.step(2)     // 确定性推进 2 秒（不依赖真实帧率）
GAME.warp(96)    // 传送到指定位置
GAME.killBoss()  // 直接击杀大王
```

## 技术说明

- three.js r158（UMD，内联）
- 所有模型程序化生成，无外部模型/贴图
- 绘制调用 47-88 次，三角面约 6 万，中低端设备可满帧
- 相机按屏幕比例反算距离，横屏可视 15 米、竖屏 7.6 米
